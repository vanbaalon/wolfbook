# User-reported bug inventory (WLaTeX + WPaper), for regression tests

Sources: 9 WLaTeX sessions and 12 VSCodeWolframExtension sessions (JSONL). I kept only messages the user typed: `type:user` entries with origin human, plus `queued_command` attachments (messages typed while the agent was busy). Tool results, reminders, `<command-…>` wrappers, compaction summaries, task notifications and sidechains are excluded. The dump script is `dump.py`, with output in `wlatex.txt` and `ext.txt`. The fix-claim extractor is `ctx2.py`. All of these are in this scratchpad.

Out of scope and skipped: wslide bugs (1ef1c995, 72f96e5e), notebook and kernel bugs (992907b0, d57ff5f4, 71a98aa2 licence probe, issue #20), Claude Science connector (365306f5), and plain planning or feature requests. Two feature requests are listed in the notes at the end, not in the table.

Product labels: **WP** = WPaper in VS Code, **DT** = WLaTeX desktop, **EN** = engine, **WEB** = website.
Commit hashes: WPaper repo = `Extension Development`; WLaTeX repo = `wlatex/`.
